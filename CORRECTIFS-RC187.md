# Correctifs RC187

Les menus partagent désormais les gardes de sélection modifiable et de création
d'archive. Les paramètres de l'outil externe restent accessibles sans changer
l'outil choisi pour F2. Les deux destinations des terminaux sont expliquées,
le titre du renommage est harmonisé et l'aide des miniatures est précisée.

Aucune nouvelle fonction, aucune refonte, aucun changement des opérations réelles
sur les fichiers. Sept tests nouveaux reproduisent les défauts sur RC186.
Trente tests ciblés réussissent trois fois ; la suite complète n'est pas exécutée
ici. Voir VALIDATION-RC187.md pour les fichiers, preuves et limites.
