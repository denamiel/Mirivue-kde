# Modifications RC190

Les cinq simplifications autorisées sont appliquées : groupes d’aperçus,
commandes de chemins regroupées avec le presse-papiers, durée dans Outils,
KHamburgerMenu natif, KShortcutsDialog natif et conservation des touches privées.

Le dialogue KDE partage uniquement sa taille avec les autres applications KDE,
comme accepté. Annuler préserve les touches ; une erreur d’écriture restaure
les anciens raccourcis. La validation ciblée de 56 tests passe trois fois.

La suite complète et Plasma ne sont pas validés ici. Voir VALIDATION-RC190.md
pour les versions réellement exécutées, les résultats bruts et les limites.
