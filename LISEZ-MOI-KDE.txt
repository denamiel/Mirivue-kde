MIRIVUE KDE 1.0.0-beta.1 — PRÉVERSION

Ce fichier est le point d'entrée actuel. README.md décrit l'installation,
packaging/README.md le conditionnement et packaging/fedora/PUBLICATION.md
le circuit Fedora/COPR.

FEDORA 44 x86_64

  sudo dnf copr enable pdenams/Mirivue-kde
  sudo dnf install mirivue-kde

Mises à jour :
  sudo dnf upgrade --refresh mirivue-kde

Les constructions disponibles dépendent des environnements activés et réussis
dans le projet COPR. Ne pas extrapoler la compatibilité à d'autres systèmes.

CACHYOS / ARCH LINUX x86_64

Le dépôt Pacman signé existe :
  https://github.com/denamiel/mirivue-arch

Suivre son README pour vérifier la clé publique et ajouter le dépôt une seule
fois. Ne pas recréer de clé de signature sur l'ordinateur client. Puis :
  sudo pacman -Syu mirivue-kde

Les mises à jour suivantes passent par :
  sudo pacman -Syu

Installer un paquet téléchargé avec pacman -U reste possible mais ne configure
pas le dépôt. Les anciennes archives .run ne mettent pas à jour un paquet
géré par Pacman ou DNF. Ne pas écraser de fichiers pour résoudre un conflit :
vérifier d'abord l'origine des installations concurrentes.

LANCEMENT ET RÉGLAGES

Lancer Mirivue KDE depuis le menu des applications ou avec mirivue-kde.
Les éditions KDE et GNOME sont indépendantes. Ne pas supprimer leurs anciens
réglages ni les sauvegardes de métadonnées lors d'une mise à jour.

CONSTRUCTION ET VÉRIFICATIONS

packaging/README.md décrit la construction depuis les sources.
Les workflows GitHub et les constructions COPR indiquent les contrôles réellement
exécutés. Une construction réussie et un essai hors écran ne prouvent pas
l'identité du comportement avec Dolphin dans une session Plasma réelle.
