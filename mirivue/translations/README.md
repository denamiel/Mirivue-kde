# Langues de Mirivue

Mirivue conserve une seule application et traduit son interface au démarrage.
Dans **Configuration → Apparence → Langue**, choisissez :

- **Langue du système** (réglage initial) ;
- **Français** ;
- **English**.

Le changement est appliqué au prochain lancement. Les chemins, noms de fichiers,
contenus et métadonnées ne sont jamais traduits ou modifiés.
