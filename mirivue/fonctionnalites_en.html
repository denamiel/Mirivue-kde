Mirivue 1.0.0 RC162

On KDE Plasma, Mirivue can be selected as the default file manager and can receive local folders, file: URLs and KIO locations directly.

Your Media, Clearly Organised

Mirivue organizes and analyzes videos, audio, images, folders, and ordinary files locally.

Navigation and views

Use the Places panel to choose a folder. Under Plasma it shares KDE Places with Dolphin; right-click a folder and choose “Add to Places” to add it. Home, Parent, Back, and Forward act on the active pane. Ctrl+L opens the location field. F3 toggles Split View; each pane keeps its folder, sorting, and selection.

Details View displays column information and Icon View displays media visually. KDE thumbnail plugins and the shared thumbnail cache are used where available, with local media generation as a fallback. Columns can be rearranged and their profiles are configurable in Settings. Settings → Columns also lets you choose relative, regional, or ISO 8601 date display without changing chronological sorting. Right-click a header to choose automatic or custom widths and whether the view fills the available space; each pane keeps its own settings. Ctrl+mouse-wheel adjusts icons, rows, and thumbnails. Ctrl+H toggles hidden items.

In Settings → General, the Size column can show either the number of items directly inside folders — the fast default — or their total recursive size including subfolders. The former Media Content column has been removed; after calculating a folder’s duration, the video, audio, and image breakdown remains available in the Duration tooltip.

The menu bar follows the usual KDE file-manager organization: File for opening, creating, and deleting; Edit for clipboard, selection, and search; Go for navigation; View for modes, sorting, displayed information, and panels; Organize for archives, advanced renaming, collections, and duplicates; Operations for current tasks and their history. Unavailable commands follow the current selection.

Search, previews, and organization

The search icon opens a name search from the active folder, either in that folder alone or through all its subfolders. Results can be limited by item type and state; the Location column shows where each item was found. “More Criteria…” adds artist, width, or duration limits to the same search. Previews cover videos, images, PDFs, and audio artwork; the Preview Panel can be shown separately. A video starts silently at 0%, then the wheel or slider immediately unmutes and adjusts the sound; an audio file resumes the remembered volume. The volume menu can follow the system output or explicitly select speakers, headphones, or HDMI. In full screen, hold Ctrl and use the wheel or two-finger scrolling to zoom at the pointer. In a PDF, the wheel alone changes page.

F2 renames a file or folder directly. In bulk rename, files that already have their proposed name are skipped while the others continue; numbering chains are applied safely without overwriting files. A genuine conflict outside the selection does not prevent other valid rows from being renamed. As in Dolphin, right-clicking one selected folder pastes copied or cut items into that folder; on the background or with multiple selected items, Paste targets the current folder, and it is not offered on one regular file. The label states whether the clipboard contains one file, one folder, or several items. For an executable text script, the menu offers “Run an Executable” and “Run In Konsole” when Konsole is available. The menu also lets you open items, choose an application, copy, cut, duplicate, delete, create a folder, group files, and fix a suggested extension. “Delete Permanently…” keeps only its red icon and the theme’s normal hover highlight. Transfers between panes or to a Place are prepared in the background and never overwrite an existing file.

Properties provides General and Access Rights tabs for one local item. Owner, group and other permissions can be adjusted with simple lists or an advanced read/write/execute grid. A checkbox can allow a file to run as a program. Mirivue verifies the applied mode and clearly reports filesystems, such as some NTFS mounts, whose mount options impose permissions.

The context menu shows one Extract entry: the KDE service action when available, otherwise Mirivue’s extraction choices. Archive operations report progress and can be stopped. Test archives with disposable files before deleting anything.

Videos

Columns can show duration, resolution, codec, frame rate, declared bitrate, HDR/SDR, audio, channels, date and status. Mirivue reads these technical values without decoding the complete media and does not invent missing values.

A single Duration column displays either media duration or a folder’s calculated total. Video bitrate and folder-duration calculations remain visible in Operations.

Images and audio

Images show their resolution and, when available, EXIF data. Audio files show duration and music information. Metadata opens a table to edit one or more media files, then shows changes before confirmation. Suggestions never use the Internet: they only use file and folder names.

A backup is created before writing. When a format cannot safely be changed directly, Mirivue uses an XMP sidecar file. No technical information is invented.

Understanding data and analysis

Technical data are read from files; absence means that the media or its container does not provide them. Calculated bitrate measures only the first video stream, while saved bitrate was written to a compatible container after backup and verification.

Duplicates and privacy

Mirivue works locally. No file or preview is sent to the Internet. An online search opens only when you request it and after you approve the submitted terms.

Personal organization

Mirivue opens a single window by default. A second launch shows the existing window and can pass it a folder. Settings → General can allow multiple windows; this takes effect at the next launch.

File → Recent Media keeps recently opened media. Organize → Collections creates local lists such as “Watch later”; a medium may be in several collections without being moved or changed. Right-click → Personal Label offers labels such as Keep, Sort, Delete, or Share. These labels are local and appear in file status.

View → Folder Summary shows media counts, size, and the displayed audio/video duration. Unified Search can show errors, apply a minimum size, and find exact duplicates in the active folder or all subfolders. Exact duplicate search compares complete file contents; “Manage Duplicates…” then lets you explicitly choose which file to keep. Nothing is deleted automatically.

Reliability and updates

By default, Mirivue follows changes made in Dolphin, Nemo, or another application and rereads only changed files in visible folders. You can turn this off in Settings → Reliability. Analyses and transfers run in the background, one analysis at a time, so the interface stays available.

Local operations, cross-drive moves, simulated incidents, archives, media, large folders, Trash, and permanent deletion were validated on ext4 and NTFS before this release candidate. Validation commands no longer appear in the Help menu.

Before an update, the installer checks dependencies and constructs the real main window offscreen. The previous version remains available after a successful update and can be restored, while Mirivue is closed, with ./Installer.sh --rollback.

Settings and shortcuts

Settings groups automatic, light, and dark themes; columns; previews; general behaviour; and external applications. In automatic mode, colors, icons, and styles follow the desktop.

F5 refreshes, F10 opens menus, Ctrl+F searches, Ctrl+M toggles the menu bar, and Ctrl+Q quits. Settings → General lets you choose whether the window close button minimizes Mirivue to the notification area or quits it, and whether hidden items start hidden.

Context menu and integrated activity

On a folder background, “Create New” offers only a folder or a text file. “Open Terminal Here” uses Dolphin’s wording and the KDE theme icon. Commands for selected items remain grouped by purpose. MKV copies and metadata writes appear at the bottom of the main window with progress and a Stop button.

Related files and Preview Panel

Mirivue can offer to include matching subtitles, NFO files, chapters, RAW/JPEG pairs, and audio artwork when copying, moving, duplicating, or deleting. Select a video or audio file in the Preview Panel and use Play. Playback, pause, and position stay inside Mirivue; nothing starts automatically.

Media metadata

The metadata editor offers “Save in the file when the format allows it”. Otherwise Mirivue uses an XMP sidecar without altering the original media.
